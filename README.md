# MAQRI
MAQRI — Mushaf, Audio, Qur’an Riyadhussholihiin., aplikasi Al-Qur’an dari Tim IT Ponpes Riyadhussholihiin untuk membantu menjaga hafalan. Nikmati audio per ayat dengan pilihan qari, pengulangan dan unduhan offline, Mushaf Madinah 604 halaman, serta Tafsir As-Sa’di. Ringan, praktis, dan mudah digunakan.
